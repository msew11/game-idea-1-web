# 林间归途 · 网页试玩发布

本仓库只保存网页发布产物，不保存私有客户端工程源码。

- 试玩地址：https://msew11.github.io/game-idea-1-web/
- 网站文件：`docs/`；由私有客户端的手动发布流程更新。
- 游戏在访问者浏览器中运行，不提供账号、联机或云存档后端。
- 本仓库公开可下载不代表授予素材再分发许可；字体许可证随网页发布。

## 发布管理

网页在私有客户端仓库的 GitHub Actions 中构建。只有手动勾选发布、且工作流来自默认分支时，才使用本仓库专用部署密钥更新 `docs/`。每次产物提交记录来源源码提交和 Actions 运行地址；非人工会话触发的自动提交以 `Triggered-By-Session: unknown` 标记。

GitHub Pages 从本仓库 `main` 分支的 `docs/` 发布。没有自建服务器或 Docker 常驻服务，不向本仓库存入私钥、客户端工程目录或 Godot 导入缓存。
